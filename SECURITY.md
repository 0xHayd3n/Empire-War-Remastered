# Reporting a security issue

For a problem in **Empire War Remastered**, [send a private vulnerability report to this fork’s maintainer](https://github.com/0xHayd3n/Empire-War-Remastered/security/advisories/new). Please include the branch or commit, affected component (for example the local launcher, importer or multiplayer relay), expected behavior, and steps to reproduce. Do not post credentials, save files, private messages or game archives in a public issue.

For a problem in the upstream Browser Edition, its hosted site or its public relay, use [upstream’s security policy](https://github.com/Glenn332/Empire-At-War-Browser-Edition/security/policy). This fork does not operate those services.
