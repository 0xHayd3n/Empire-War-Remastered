# Commander network

**Home → Bell → Enable social.** Give this browser a callsign on the selected relay. Copy the 16-character **friend code** and exchange it with the other player. They send a request; you accept. Only accepted friends can message or invite each other. The bell counts incoming friend requests and lobby invitations. Social is optional: there is no directory of players, and opening the game does not enroll anyone. This is not Steam Friends, a global account or a push-notification service.

**To play together:** host a custom game on the same relay and build. From joinable staging choose **Invite friends**. Copy the code/link, or send a personal invitation. The recipient returns to Home, opens the bell and explicitly chooses **Join lobby**. They join the native staging room, not a running battle. An invite expires after ten minutes, can be withdrawn, and does not reserve a slot. If the playset differs, open the matching edition and ordered mods before trying again. Password rooms retain their native workflow; reserved operation matches cannot be invited into. A host can leave or fill the room between sending and acceptance.

- A `127.0.0.1` game link opens the recipient’s own computer, not the host’s. Across machines, use the room code or the addressed invitation in the compatible game and configure **the same reachable HTTPS relay** under **Relay settings**. For two disposable browser profiles on one machine, `npm ci --prefix lobby` then `npm run relay:local` serves loopback port `8787`. The public relay needs its own authorized deployment and migration before it supports social.
- Device identity is scoped to the relay. Universal’s shell keeps the same friend code across its era frames on that browser. Separate standalone game origins or browsers have separate identities. Clearing site storage loses access; there is no password or recovery service. A link never contains a device credential. The relay and native staging callsign are separate: changing a social callsign does not rename a player in someone else’s game.
- **Manage** lets you change callsign, hide recent activity, change relay, remove friends, block and unblock. Removing or blocking clears the pair’s thread and outstanding invitations. Unblocking does not restore friendship. “Active in comms” means recent contact with the service, not necessarily available for a battle. The roster polls while its panel or title is visible; it is not an OS notification listener.
- The relay stores a digest of the random device key, a display name, mutual contacts and limited messages. The commander code is intentionally shareable; it cannot authorize actions. Recent text history is limited to 32 messages per pair; entries older than seven days and expired invitations are pruned on subsequent use. Text is visible to the relay operator, not end-to-end encrypted. Choose a relay you trust. Native Steam subscriptions, saves and campaign data are not used.

`npm run test:social` checks the actual relay worker and exercises two independent Chrome profiles against local Universal game data. It uses temporary relay and browser storage. Install Chrome, run `npm ci --prefix lobby`, and make Playwright available with `npm install --no-save --package-lock=false playwright-core` in the checkout root. No public service or player profile is used.
