# Playing Empire War Remastered

For installation and the differences from Browser Edition, start with the [project README](../README.md). This guide covers navigation, local collections and controls in the Universal development build.

## Title menu

Normal startup opens **Home**. The gold **Play** button sits at the top center with notifications attached on its left and settings on its right. Both drawers slide in from the right. Use **Close sidebar** or Escape before opening the other drawer; reduced motion skips the slide. There is no Home button. The illustrated **Workshop** and **Army Painter** tiles sit beside **Continue Campaign** (below it on small screens). Inside a section the dock disappears. The Back arrow sits at the left edge of the section, separate from the centered title; Escape does the same. **Play** opens with Single Player selected. Switch between the two tabs by click, tap, or left/right arrow to see that side’s modes in place. Either tab backs directly to Home. Matchmaking keeps its own bottom Back control. **Continue Campaign** shows your latest Galactic Conquest checkpoint. **Choose campaign…** lists the current profile’s Galactic Conquest saves by name and time. Use its **Game profile** selector for an older Universal campaign; changing profiles reads the actual saves in that era. This does not change which save one-click Continue uses. With no checkpoint, choose **Explore modes** instead. The Home bell opens the [commander network](commander-network.md) for friend requests, messages and lobby invitations; the cog opens **Settings**, **Credits** and **Exit Game**. A mod with unfamiliar dialog controls keeps its native layout.

**Single Player** has cards for Galactic Conquest, story campaigns, skirmish and Instant Battle, alongside Tutorial and Load Game. Use **Load** on a mode tile to see matching saves, or **Load Game** for the full single-player archive. New conquests write an opening checkpoint when the campaign can safely be saved; Continue uses the newest available conquest checkpoint or manual save, not a new game or an unrelated battle. It is not a continuous autosave. In Universal the host remembers the save's era without copying the save. Pre-update saves in another era are indexed when you browse that era's saves; old instant battles without a mode marker remain accessible from the full archive. The original Internet and LAN lobbies and their multiplayer saves remain under **Multiplayer → Custom games**.

**Workshop** opens the [HoloNet Exchange](workshop-exchange.md): browse illustrated tiles and inspect a mod’s source, availability and collection membership without changing the running game. **Base** means the original mod. An alternative **Native** edition appears only for a separately identified, author-verified stripped release; none was verified in the current library. Universal compression is not a Native edition. Browse by category, create personal categories, or search by name or Workshop ID. The dossier separates the source, local installation and playset membership. It links Mod DB when the publisher confirms the mirror. Steam handles subscription and unsubscription; the menu opens the exact item or shows a manual item-specific download command for eligible items. Watch observed installation and app-wide transfer status, then **Refresh**. Alternatively, import an authorized `.tar` into browser storage with measured progress, or remove that browser copy without touching Steam or saves. For unnamed items, **Look up titles** asks before sending those item IDs to Steam. Add installed items to **My playset** (or use a collection’s enabled order), then move items up or down: the first item wins conflicts. Name and save different playsets, then recall one with **Use saved**. **Prepare playset → Open playset game** starts a separate local game without replacing Universal. The same ordered IDs reuse the same local save origin. A playset can have at most one known primary overhaul; compatibility and dependencies of arbitrary submods are not guaranteed. Up to three distinct playsets can be prepared per Universal session. Non-Universal sessions show mounted content and link back to their import page.

**[Army Painter](army-painter.md)** previews ground troops and ships with your faction's colors and pattern. Save and equip a named livery for solo or multiplayer battles, or equip stock markings. Its **Fleet registry** button opens the [deployment workbench](unit-armory.md). Select a profile and faction, then turn, zoom or reset a unit’s actual mounted 3D model. A horizontal unit selector preserves the camera and fleet draft. Supported models have their native idle clip; a low-power portrait mode and text record keep deployment usable without 3D. Save a **flight card** for that unit: a lead count and optional companion. In single-player Instant Battle, **Add flight card** appends those units to a matching fleet. For a complete fleet, **Fleet preset → Apply preset** replaces the roster with a saved blueprint. Existing blueprints remain usable; missing units, duplicate heroes and over-budget orders are rejected without changing the fleet. These are deployment choices, not changes to unit stats, cosmetics, campaign or multiplayer rules.

**Play → Multiplayer → Matchmaking:** in the [matchmaking lobby](play-operations.md), choose **Playlist → Social or Ranked → ruleset → Use playlist**. The lobby has its own clear orbital backdrop, a commander roster and a bottom **Back** control (Backspace or Escape). **Connection** configures only this queue. **Start matchmaking** gives you five seconds to cancel before searching for another compatible commander. Paired commanders have 15 seconds to vote on up to three maps from their ruleset’s mounted pool. The selected map opens in native staging; both players still ready before battle. Ranked tracks completed outcomes on this device, not on a public ladder. **Custom games** bypasses the countdown and queues entirely: Internet, LAN, hosting, invitations and join-by-code still work separately.

**Local multiplayer relay:** from the checkout run `npm ci --prefix lobby` once, then `npm run relay:local`. Keep that terminal open while using multiplayer from Universal. The command runs the existing lobby worker on loopback port 8787; it does not publish a service. Two independent browser profiles on this computer can use that relay. Across computers, both games need the same reachable relay, not each computer's own `localhost`.

Tile screenshots are private local derivatives, not distributed assets. To prepare the curated thumbnails on another PC, run `python tools/import-title-art.py "path/to/The Folder of screenshots"` with Pillow installed. This leaves the originals untouched. The local server reads only the named thumbnails from `%LOCALAPPDATA%/EaWBrowserWorkshop/title-art` (or `SWR_TITLE_ART`); the bundled briefing illustrations cover missing photos and hosted play.

The background is a still, not a running battle. A local game server can show the same verified Coruscant orbit photograph used for campaign loading; installations without that photo use the bundled orbital illustration. Neither backdrop delays navigation. The data-import page, Workshop launcher and in-game HUD are separate from this menu.

### Universal library: one game, separate overhauls

Stock requires no pack build. For installed parent mods, run `npm run universal:build` once, then `npm run universal` or double-click **Universal Library.cmd**. The [Universal game](http://127.0.0.1:8590/) opens directly to the title menu. Windows users can also [register a one-click launch URL](universal-library.md#click-a-url-to-start-universal-windows) to start it even when the server is closed. Choose **Play → Single Player → Galactic Conquest** for one setup board. The title and Back chevron sit on the galaxy, leaving the sidebar for setup. Choose an era card at the top of the setup panel. Choose **Time-based** for a supported starting period or **Scenario-based** to browse without a calendar. The map list shows each map’s mod and color-coded planet count. Scenario tabs filter by type; unavailable mods have grayed-out entries with a link to local submod details. Below it, **Faction** shows the eligible factions’ hero cards; **Settings** holds difficulty and campaign rules. A gold outline marks your selection. The preview frames the selected map’s sector of one shared galaxy, drawing its planets and routes without starting a simulation. The faction key is always visible. Difficulty, [campaign rules](universal-library.md#start-a-campaign-and-choose-its-path) and applicable starting conditions share the same screen. **Start campaign** launches the displayed setup; there is no separate era or rules page. In New Campaign, an era card reveals its stories with color-coded planet counts. **Info** opens first with the story and starting treasury when known. Other factions present in the campaign appear grayed out and marked **Not selectable in this campaign**. You must choose a playable **Faction** before starting; **Settings** uses the Galactic Conquest difficulty ticks. Skirmish and Instant Battle show all installed battlefields on one chart without trade lanes. Each named planet appears once on the chart, regardless of how many maps use it. Search or click a world. Skirmish opens with no battlefield selected. Zoom in for collision-aware planet names, then expand a planet to choose a Land or Space variant. The footer shows the chosen map’s preview when available and color-coded seats grouped by team. Instant Battle uses the same searchable, expandable **Battlefield** sidebar, with the fleet editor under **Forces**. Neither mode needs a profile picker. Skirmish **Settings** accepts typed starting credits and unit caps beyond the former slider maxima. Faction families use verified installed crests where available. Unaffiliated forces without an emblem use a neutral command marker. In **Teams**, choose a faction for yourself and independently for each ally or opponent. Opening **Teams** shows the commander ring alongside the assigned players. Each card shows a close-up rendered from its commander’s actual model over the faction crest and colour. Click the leading strip to change only the participant’s battle paint. AI difficulty and **×** (remove) stay on the card. Drag a player to a team or onto **Create team**; the move grip and destination also work with touch or keyboard. Extra teams require a generated space field; moving a player never silently substitutes a battlefield or roster. Team determines alliance and shared bases, not who supplies the units. Select a player card, preview a commander, and press **Assign**. The ring stays open for the next choice. You can also preview a new commander first, then select the player who should receive it. Only **Assign** changes that player’s roster. The grid icon to the left of Search opens the faction directory over the dimmed preview. Each group contains cards for its exact rosters: a close-up rendered from the equipped figure in front of its faction crest, followed by the figure’s name and faction. Search for a commander, faction, group or mod. Pick a card to preview that roster, or pick a group heading to browse the group in the ring. Group tiles use overlapping crests from their own members. Each category header spans four compact commander cards. Categories sit in pairs when space allows, stack on narrow screens, and center their partial rows. Clear the stage search to return to the full ring. Escape closes the directory without changing your preview. The figure arrows and swipe still browse individual rosters. Each member keeps its own insignia and roster. Search still works across commanders, eras and mods. Figures fade into focus over a faction-colored land scene; the name, era dates, mod and **Assign** button follow the focused figure. The crest above the commander is a still HD emblem in that roster’s in-game shade. Shared faction insignia follow the [commander heraldry guide](commander-heraldry.md); commanders and armies still belong to their original packs. Behind the figure, the faction device rotates and floats in 3D, lit in the same roster shade as the crest. The scenery and manual team paint stay independent. Reduced motion holds the projection still. Figures carry the equipment their installed models and hardpoints specify. Assigning uses that exact roster; browsing never changes a seat. The stage draws animated installed characters and infantry, not ships, tanks or portrait cards. Selecting one does not spawn an extra hero. Each seat keeps its source even when the opponent is from another era or you change maps. Native factions use their home roster when supported. Guests and campaign-only factions use tactical detachments drawn from their source mod’s armed units, with host production facilities. A faction with units in only one domain cannot start in the other. Land Instant Battle deploys ground companies without skirmish bases. Full skirmish staging and fleet outfitting are still available through **Players & options** and **Edit fleets**. It doesn't merge campaigns or modify Workshop installs. See [build, disk usage and switching profiles](universal-library.md).

### Play an installed Steam Workshop stack

**On your PC:** install mods through Steam, then double-click **Workshop Launcher.cmd** in the checkout (Node.js required). The local
launcher opens in your browser. It finds the game and Workshop items in Steam's libraries, reads any saved Mod Collection Launcher v1
FoC profiles from `%LOCALAPPDATA%/ModCollectionLauncher/profiles`, and displays collection cards using artwork from the installed mods.
The local selector at `http://127.0.0.1:8490/` fills the viewport, cropping scene edges when the screen and image differ in shape. Hover or focus a logo tile to highlight it; select a tile or use the carousel arrows to switch collections. **Launch** is a separate action. **Enabled mods** shows launch priority. Music requests audible playback on arrival. If the browser blocks first-visit autoplay, a click, tap, or keypress starts it. It follows the selected collection, pauses in a hidden tab, and can be muted from the browser tab. Reduced motion leaves the art still. Collection artwork is read from `%LOCALAPPDATA%/EaWBrowserWorkshop/collection-art` (or set `SWR_COLLECTION_ART` to your desktop launcher's Assets directory); `<Workshop ID>.png` overrides a scene and `<Workshop ID>-wordmark.png` overrides a transparent logo. A collection without a logo shows its name. Preview tracks come from `%LOCALAPPDATA%/ModCollectionLauncher/music`, including `<Workshop ID>.mp3` overrides. If a desktop theme is missing, the selector uses available installed media; it does not download songs or bundle the artwork. Browser UI text uses [Oswald](https://open-foundry.com/fonts/oswald), served locally with its [SIL Open Font License](../public/fonts/oswald/OFL.txt); original game-rendered text is preserved. **Launch** and the outline play triangle in **Library tools** start the same browser game. **All installed mods** shows the full searchable inventory, including members of saved collections. **Refresh** rescans Steam and the saved profiles while no session is running. If names are missing, **Look up Steam titles**
requests them from Steam only when clicked. In a battle or on the galaxy map, press **F2** to view frame times.
The library stays available while playing. Save and leave the game, then use **End session** in the library before switching collections.
To browse the loading artwork without leaving your game, open `briefings.html` on the **game** server in another tab (normally `http://127.0.0.1:8478/briefings.html` during a Workshop session). The gallery shows transition contexts, not a catalog of map photographs. Local Workshop tactical battles can show reviewed 1920×1080-or-better photographs of the exact installed land or space map. Space and land battles share a briefing: the location, battle type, and one authored world description on the left in white Oswald, with live loading progress below. Above the readable title, the same place name appears in [Aurebesh AF Canon](https://www.fontspace.com/aurebesh-af-font-f49637) by AurekFonts (public domain, served locally). If the mounted data has no world description, the paragraph is omitted rather than filled with tactical advice or another planet's history. Without a verified photograph the briefing is text-only. It never guesses from shared loading screens, filenames, planet icons, galleries or minimaps. The battle opens automatically at simulation readiness, without waiting for art or input. Multiplayer uses the same briefing, with player loading progress shown separately; peer readiness still controls entry. No mod artwork is bundled.
Neither Steam nor the old launcher's profiles are modified. Close the local server to stop the launcher.
Alternatively run `node server.mjs --workshop` and open the printed address. For a nonstandard Steam installation set `STEAM_PATH` to the
Steam client folder containing `steamapps/libraryfolders.vdf`. This local mode does not need an npm install or a native build.

**On the hosted website:** a website cannot inspect your Steam libraries automatically. On the start page, open **Mods → Use Steam Workshop launch options** and paste the author's
`STEAMMOD=…` entries, submod first if that's the published order. **Use this order** enables just those items from the mod list. The first
entry has the highest priority; the list shows overlays from bottom to top. You can save the selection as a mod profile or start a game.

The Windows app discovers installed items. In a browser with directory-picker support, **Choose 32470 folder and apply…** lets you select
`steamapps/workshop/content/32470` in your Steam library and read just the missing numbered folders. In other browsers add each numbered
item folder first. If an item is missing or appears twice, the existing selection is left alone. The page does not subscribe, download,
execute a Steam command or change the installed files.

[progression.md](../progression.md) shows exactly what is finished, what is partial and what is still missing.

**For fork maintainers:** use the [proposed fork mod compatibility standard](fork-mod-compatibility.md) to check
that unchanged mods work on your build as they do on a named main web build. Every fork, including a fork of a fork,
tests its own release directly against main; mod authors do not need to port or repackage anything.

## Controls

The controls are the same as the original:

| | |
|---|---|
| Left click / drag | select, box-select (Shift adds, double click selects the same type) |
| Right click | move, or attack what is under the cursor |
| Ctrl + right click | attack-move |
| M / T / F / G / X | move, attack, attack-move, guard, stop |
| WASD / arrows / screen edge / middle-drag | pan |
| Wheel / Q, E | zoom / rotate |
| Ctrl+1…9, 1…9 | set / recall a control group |
| P, + / - | pause, game speed |
| Esc | cancel, deselect, menu |

In land and space strategy views or on the galaxy map, park the mouse at an edge of the battlefield to scroll; move inward to stop. Edge scrolling is on by default and can be disabled with **Pan the camera at the screen edges** in Game Options. It does not steer a possessed soldier or vehicle.
