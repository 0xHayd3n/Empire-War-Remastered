# Fleet registry

Open **Home → [Army Painter](army-painter.md) → Fleet registry** and pick a profile and faction. The selected ship occupies the inspection bay. Choose another in the horizontal flight line, use the previous/next controls, or filter by class and search by name, role or roster ID. Selection does **not** add a unit or reset the camera, fleet draft or other units’ edited flight cards. The separate **+** adds one copy to the blueprint. The list is the actual `instantRoster`, not every XML object in a mod. With a unit focused, arrow keys browse the roster and Home/End go to its ends.

The previous registry gave the catalog, still and planner equal space; enlarging a picture didn't let you inspect the bow or underside. The bay instead separates **look** (one live camera), **choose** (the flight line) and **deploy** (the orders below). The identity strip shows the localized unit, role, price and space population. **Unit record** includes the roster ID, available native encyclopedia copy and resolved complement. For squadrons and companies the feed identifies the representative hull; sizes are framed for inspection, not compared at a shared physical scale.

**Live model:** drag to orbit. Click or Tab into the camera to use arrows, +/−, or Home to reset. The wheel zooms only when the camera has focus; the zoom and reset buttons work without a mouse. On touch, drag horizontally to turn, swipe vertically to scroll the page, and tap +/− to zoom. The preview renders the mounted ALO with the engine’s native model/material path and textures, under inspection lighting. It doesn’t run ship AI, combat, particles or campaign scripts. Only a bound, multi-frame `SPACE_IDLE_00` or `IDLE_00` clip enables the idle control. Static craft do not get invented movement. Reduced motion starts idle playback paused.

**Portrait · low power** releases the 3D renderer and remembers the preference; missing models or unsupported graphics also leave a command portrait or text record. A settled selection owns one disposable render worker. It reads through the page’s exact VFS; individual preview reads are capped at 32 MiB, with a 96 MiB per-hull receipt budget. One camera frame can be in flight; a static hull renders on demand, visible authored idle at up to 24 fps. No clock runs offscreen or on a hidden page. The first visible hull starts without the roster-browsing delay; texture and native idle reads overlap context setup. Changing hulls disposes the previous worker. Leaving for another title section may park **one fully drawn hull** with no frame clock for up to 15 seconds. Reopening Customize in that title restores the selected faction and unit, not discarded orders. An exact mounted-hull/color match reuses its ready renderer and draws a new interactive frame. A different selection, portrait mode, a hidden page/title, a new runtime or the timeout releases it. Nothing is written to disk for this cache.

## Two different saved orders

- **Flight card — add.** Set the selected unit's **Lead count**, optionally choose a different same-faction **Companion** and its count, then **Save flight card**. Each lead unit has one editable card per faction and content profile. For example, a fighter squadron can be saved with two more copies and a single escort. Counts are **roster entries**, not individual fighter models inside a squadron. This is a deployment order, not an upgrade, skin, automatic formation or AI assignment. **Add card to blueprint** also works on the current unsaved card; later card edits never change an existing blueprint.
- **Fleet blueprint — replace.** Mix roster entries and cards, remove unwanted copies from the manifest, give the fleet a name and **Save preset**. The four class totals show its composition. Saving a blueprint doesn't also save a card. Leaving or switching faction warns before discarding unsaved changes; inspecting another unit keeps its temporary card edits while you browse.

In **Play → Single Player → Instant Battle**, choose the same profile and a matching fleet. **Flight card → Add flight card** appends the two counts to its current army. **Fleet preset → Apply preset** replaces the army with the saved roster IDs, in order. Both display the effect before committing and check the entire result against the current roster, unique heroes, 256-entry preset limit and the selected fleet's budget. A refusal makes no partial change. Missing or renamed units aren't silently substituted. No network fleet, campaign save, tactical unit definition or balance table is modified.

## Compatibility and checks

Existing `swr-fleet-presets-v1:` keys and `{id,name,faction,units}` blueprints remain in place. Cards use a separate local key derived from the same edition, ordered mods, versions and pack revisions. If Universal's mounted metadata is missing or inconsistent, its document pack/revision separates that namespace from stock and other packs; unknown old data is not copied into it. A damaged or blocked store isn't overwritten on save.

Install Chrome and run `npm install --no-save --package-lock=false playwright-core` in the checkout root for the browser checks below.

- `npm run test:title-latency`: cold first interactive frame vs. repeated section visits, live asset/worker reuse and idle cleanup. Timings are local measurements, not hardware-independent deadlines.
- `node tools/test-unit-armory.mjs`: old keys and payloads, isolated layers/revisions/factions, exact card composition, invalid counts, over-budget and duplicate-hero rejection, damaged storage.
- `SWR_TEST_WINDOW_PORT=9050 node tools/check-unit-armory.cjs` (Git Bash): local Chrome, installed stock game and built Thrawn’s Revenge and Fall of the Republic profiles. Uses a disposable browser and temporary Universal library; allows eight consecutive ports in 9050–9069. Checks textured native hull pixels after a camera turn, zoom and reset, rapid switches, renderer teardown, missing art and portrait mode. An isolated stock Lancet ALO/ALA exercises actual animation, reduced motion and offscreen suspension without adding it to the playable space roster. The normal menu path tests touch orbit vs. page scrolling at 375px, legacy blueprint, edited card, live Instant Battle fleet replacement/addition/refusal, and mod/faction isolation. Optional `SWR_DESK_SHOTS` points to an existing screenshot directory. This verifies **staging**, not combat AI or every installed mod.
