# Universal campaign library

One local start screen for stock Forces of Corruption and six separately playable overhauls. It is **not** a merged ruleset, a Steam upload, or a change to your subscribed items. Use the normal Workshop launcher for a saved collection with multiple ordered submods.

1. Install stock and whichever parent mods you want through Steam. From the `universal` checkout run `npm run universal:build` to import all supported installed parents, or e.g. `npm run universal:build -- 1125571106` for Thrawn’s Revenge alone. Stop Steam updates during import. Stock needs no import.
2. Run `npm run universal` (Windows: **Universal Library.cmd**) and open **http://127.0.0.1:8590/**. The game goes straight to the Forces of Corruption title screen. There is no launcher shelf or mod selection before the menu.
3. Choose **Single Player → Galactic Conquest**. Choose one of the four era cards. Under **Time-based**, drag the calendar dot to a starting year. The marks are spaced by elapsed years, including fractional years; arrow keys step between supported starts, and Home/End jump to the endpoints. Fall’s prewar FTGU opening has its own labeled stop before the calendar. Choose **Scenario-based** to see scenario maps without a time-period selector. Returning to **Time-based** restores the previous period. An era with only scenarios opens the scenario list directly. Compatible maps appear in one table: **Map | Mod | Planets**. Mod identifies the source storyline; you don’t have to select it first. Expand a map name to see its indented sizes, then choose a size to preview it. The parent shows the smallest to largest playable planet count for the current period. Opening or closing it does not change the campaign. In **Scenario-based**, the full-width **Story**, **Random**, **Sandbox**, and **Miscellaneous** tabs show one list at a time. Empty tabs are omitted. Planet counts under 50 are red, 50–99 amber, and 100+ green. Each end of a range has its own color. Grayed-out map lines and their **Requires [mod]** tooltips identify supported mods without a usable local pack. Click one to view its placeholder submod page, then close it to return. It does not install anything, change your selected map, or supply unverified dates or counts. A range on an individual map means its available variants differ; selecting one shows its exact count. For a scripted selector the count describes its setup map, not a promised final galaxy. **Scenario-based** includes undated, scripted and historical range scenarios without inventing a start year. Click a map to preview it. Switching periods keeps the selected map if it fits; otherwise choose another map before starting. If a map has distinct starts in the same period (such as the 6 ABY Imperial regimes), pick the variant under the map. Below the maps, use **Faction** to choose a supported faction and **Settings** for difficulty, economy, politics and other options. Switching these tabs keeps your choices. **Start campaign** stays in the footer. Only installed or fully materialized campaigns can start. Escape returns to mode selection; **Reset** restores defaults without changing faction or map. Skirmish and Instant Battle open their own staging screens after the era choice; Load Game looks in the selected era’s saves. A story mode without a native story entry explains that its listed campaigns are under Galactic Conquest.

The outer game window stays at the same address. The engine loads only the selected era’s runtime when needed, rather than mixing conflicting Lua or XML in memory. Per-era frames retain the same stable loopback origins as the previous library, including their save stores and workers. Keep ports 8590–8597 available. Change the block with `SWR_UNIVERSAL_PORT`; changing it changes where the browser looks for saves. Built pack manifests need no conversion.

### Click a URL to start Universal (Windows)

From this checkout, register the on-demand link once for your Windows user: `powershell -NoProfile -File tools/universal-game-link.ps1`. Then open `eaw-universal://play` or double-click **Play Universal.url**. Windows starts the local server if needed and opens the title screen in your default browser. Clicking again reuses the same running Universal instance. Your browser may ask permission to open the app. No administrator rights, sign-in task, public hosting or file uploads are involved.

The ordinary `http://127.0.0.1:8590/` bookmark works while the server is running. For a separate instance, pass e.g. `-Port 8600` at registration; the link then always opens `http://127.0.0.1:8600/`. Different port blocks have separate browser saves. The link never stops another listener or silently changes ports. If you move the checkout, remove the registration first and register again at the new location. To unregister: `powershell -NoProfile -File tools/universal-game-link.ps1 -Remove`.

### Start a campaign and choose its path

Each era has one split crest, with the card background shaded from the faction on its left into the one on its right: Jedi blue / Sith red, a red Republic cog on white / Separatist blue, Rebel ember / white Imperial cog on black, and New Republic gold / the same white-on-black Imperial half. Hover a card for the faction names. Gold still marks the selected era. These setup icons need no logo download, Steam cache or extra pack.

The settings panel runs the full height of the right edge. The rest of the window shows the starting galaxy with its faction key. A neutral starfield is visible while the atlas opens. The native sky fades in over it. Selecting a different region eases the camera to that sector; changing years on the same map keeps your chosen zoom and pan. Incoming routes and rings fade in against the shared sky, never over the previous campaign's foreground. The system’s reduced-motion setting skips these transitions. Wheel over a planet to zoom smoothly about the pointer, or double-click its name to center and zoom; drag to pan only when zoomed in. The frame stops at the edge of the galaxy image. With the map focused, +/− zoom and Home restores the whole-galaxy overview; Escape leaves setup.

Pick a faction by its hero card. A gold glow marks the selection. The portraits and emblems come from that storyline’s locally mounted art; a representative is not necessarily a starting unit. Each owner in the map key gets an emblem, a faction unit icon if no emblem is supplied, or a color-coded monogram when neither is available. Difficulty, treasury per planet and objectives are single-choice lists. The economy/politics preset and political control per point sliders snap to the available settings, not arbitrary values. Use the arrow keys on a focused slider to step between them.

Every setup map occupies the same galaxy. Universal uses the galaxy art and perspective from one installed reference chart (Thrawn’s Revenge, Fall, Revan, then stock) and keeps it while changing campaigns. The preview omits the backdrop model’s decorative region borders (such as the Outer Rim and Core). It keeps the starfield, playable hyperspace lanes and ownership rings. When zoom would enlarge the overview beyond its pixel resolution, the native renderer redraws the visible lanes and rings at viewport resolution using the selected map’s own geometry, colors, textures and blending. One anchored detail image covers the close-up; it is discarded on a map change. Gameplay and installed art are untouched. Shared planet identifiers align each profile with the reference chart. On-map and off-map worlds use the same 128-pixel portrait tiles and six-pixel diameter at whole-galaxy fit. Planets scale with the chart camera, not the era’s gameplay `Scale_Factor`. Names have no shadow: they grow more slowly on approach, then taper from 13 to 11 screen pixels at close zoom so they don't crowd the planet. Off-map portraits and their names share a monochrome layer at 20% opacity. They yield to selected planets, ownership rings and names at every zoom. Hovering an off-map dot can reveal its name only where it fits without covering the selected map. Hover follows the pointer as the camera moves. Crowded names keep a usable position and fade in or out when their visibility changes, rather than blinking on each zoom step. Active names render at screen resolution and fade at the viewport edges; names already in view stay steady. Active planets use their selected map’s authored formation under a common scale, rotation and translation; a shared identity does not force a planet back to its reference position. This is a game chart, not a claim of canonical coordinates. Off-chart setup markers are labeled as uncharted. Only the selected campaign supplies active planet art, lanes, rings, owners and the planet count. Gray context worlds never supply extra lanes or playable locations. Nothing changes the simulated map or its saved coordinates. It shows initial ownership, not fog of war, fleets or story changes. Names and ownership remain available while the art loads or if a model cannot be rendered. Other modes keep their existing presentation.

On the reviewed Fall of the Republic and Revan’s Revenge progressive maps, **Time period** filters the maps and selects a concrete destination. Thrawn’s Revenge also exposes progressive, regional and historical starts where its local selector tables enable that map, faction and date; its two supported 6 ABY Imperial regime destinations appear separately. **Start campaign** goes straight to the displayed scenario on the target pack’s own origin. No placeholder galaxy, scripted reload or transfer of saves. Fixed scenarios keep their authored start. Specialized custom maps, Thrawn’s minor-warlord selector and unrecognized loader revisions are not translated by guessing at Lua or exposing every unlisted XML entry. Use the original selector for those supported by the mod.

**From the Ground Up (FTGU):** In Clone Wars, move the slider to **FTGU · pre-22 BBY** for Fall’s single-planet start. This selects displayed tech 1 with the chosen faction’s adjustment; the gap before 22 is a named opening, not a year estimate. In New Republic, the first tick **4 · FTGU** lists Thrawn’s standard FTGU map first, followed by the other 4 ABY maps. Its **Era progression** setting preserves the mod’s static/progressive choice. Later and specialized FTGU selections remain in the original selector. In Old Republic, **3996 BBY** opens Revan’s Era 1 FTGU for the Sith Empire, Galactic Republic or Mandalorian Clans. The FTGU script reads the local faction’s starting credits to pick its era. The dated start therefore keeps the authored zero-credit default rather than overwriting every faction’s treasury. For the original configurable starting credits, use the same FTGU map under **Scenario-based**.

Universal prepares a private compressed catalog per stock fingerprint, pack revision and language under `campaign-atlas-v1` in the library directory. First use after an update or language change may wait for indexing. After indexing, changing the selection updates the names and ownership immediately. During indexing, each pack’s mounted model geometry, diffuse maps and clouds are rendered into small private PNG sheets under `planet-portraits-v1`. The chooser prioritizes the selected map, then loads the entire installed portrait library (up to four sheets at a time). Once decoded, the same pictures are drawn at display resolution during pan and zoom; they are not an enlargement of a low-resolution map screenshot. Locations whose source model is invisible or particle-only get a neutral shaded marker instead of an invented surface. For ordinary small route textures the private index stores the exact winning bytes per profile; the native renderer can draw the shared sky and switch lanes/rings without reopening each pack’s art mount. Larger texture sets keep the isolated renderer path. Escape releases the worker. For up to 45 seconds the page can retain one opening plate, one opening still and at most four opening portrait sheets for a quick return to the same atlas and viewport. Generated sheets are local game derivatives: do not distribute them. There is no continuously running preview simulation. The shared galaxy render is reused across storylines at the same viewport size; a bounded in-memory cache also keeps the last three campaign views. Zoom and pan crop the rendered chart without loading another map. Browsing does not start another game server, navigate the game or run campaign scripts. A failed launch mount leaves the board and selection intact. No pack rebuild is required just to enable the catalog.

**Authored objectives** and **Campaign defaults** are preselected. The chooser uses listed single-player variants and verified setup-loader destinations. Tutorial and multiplayer use their normal title-menu routes; the separate Workshop launcher is unchanged.

- **Star Map Expedition** is an optional, original adaptation inspired by Revan’s Revenge’s Star Forge search. Building the Revan pack unlocks it in *other* profiles. When an eligible map has at least one connected, selectable non-allied surface world, setup previews up to three sites by name. Gain control of each once to earn a 3,000-credit grant under the host campaign’s credit rules. Progress is reported in the galactic log and saved, including on a tactical return. The objective does not change victory conditions or spawn the original Star Forge, finale, ships or characters. Story restrictions can still affect when a site is accessible. Revan’s own profile keeps its authored path.
- **Economy and politics preset** applies a built overhaul’s treasury cap and political-control transition time together. You can then change either value independently, or select **Campaign defaults** to reset both. Choices come from explicit numeric declarations in your built packs, with identical values grouped and labeled by source. They affect all factions in this campaign, not the global database or your next game. Default means the mounted campaign’s value. The save carries the resolved values; you do not need to remount the donor to resume.

This is a curated catalog, not automatic Lua mixing. A filename or a similar-looking function is not enough to import a faction government, unit roster or scripted story. Each additional system needs a defined effect, compatible targets and a save/restore check.

### What is stripped

A profile is a manifest of the **winning parent layer**: virtual path → SHA-256 object (or a deletion). It does not copy the stock game. MEGs and loose overrides use the original resolver; paths the parent deletes remain absent. Identical bytes, even at different paths or under different names, occupy one object in the library. Different bytes at the same path remain separate, including scripts, localization, campaign XML, textures and models. Every profile keeps its own virtual paths and primary Workshop ID. There is no requirements guess based on filenames, and no attempt to remove individual Lua functions from nonidentical scripts. Functions with the same name need not have the same behavior or callers.

The default build hashes the effective mod files and writes **manifests only**. On first access the local server copies the needed object from that parent, verifies the digest, and atomically publishes it in the shared cache. Keep the parent installed in this mode. A changed uncached file is rejected, not silently substituted; end the session and rerun the build after updates. Other parents do not need to be installed to play the selected profile.

To make an independent **local** copy of the mod payload, run `npm run universal:build -- --materialize` (optionally append specific primary IDs). This eagerly fills the same object store. A fully materialized pack no longer needs its Workshop folder to play, but **always requires the stock game**. Budget disk space before doing this. Neither build mode deletes any Steam files. Updating packs leaves old objects in place; to start over, stop the library and delete only its generated library directory, then rebuild. Browser saves are separate.

The default output is `%LOCALAPPDATA%/EaWBrowserUniversal/library-v1` on Windows (home directory fallback); set `SWR_UNIVERSAL_LIBRARY` to use another private disk. Keep the directory outside the repo and Steam installs. Generated manifests, mod metadata and payloads are local; this repo distributes only the builder, launcher and synthetic tests. Do not redistribute the generated library without the relevant rights and permissions.

### What was verified

For the six installed primary versions in the first import, the effective mod layers totalled **117.56 GiB**, with **76.02 GiB** of distinct payloads by SHA-256: **41.54 GiB (35.3%)** need not be copied twice, including duplicates within as well as between profiles. This is a comparison with six *separate expanded mod-layer copies*, not observed free disk, a smaller Steam download, or a performance claim. It excludes stock, manifests and filesystem overhead.

For all six, the full mounted virtual key sets and sizes matched a direct stock + parent mount in English and German; 35 representative whole mod files also matched byte-for-byte. `npm run test:universal-library` checks synthetic cross-profile sharing, divergent scripts, tombstones, MEG and loose inputs, TGA lookup, ranged reads, stale/corrupt bytes, and reading a fully materialized pack with no parents present. The earlier library verified stock and six pack mounts. `tools/test-universal-window.cjs` is an opt-in Chrome check of the native mode buttons, direct conquest board, storyline switching and recovery, inline rules, and exact campaign launch. It requires local built Revan and Awakening of the Rebellion packs and `playwright-core`. Set `SWR_TEST_ALL_ERAS=1` to exercise the board in the other four installed skins as well. These checks do not establish complete campaign or multiplayer parity.
