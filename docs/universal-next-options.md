# Next Galactic Conquest setup options

Follow-up to [the first setup audit](universal-setup-candidates.md), after Fall’s layouts and production payment shipped (`acb1b49`). This note records the original proposals and their source evidence. Workshop paths below are relative to that item’s `Data/`. The initial audit was source and simulation only. The subsequent implementation and player-facing limits for Thrawn openings, transport losses and stock Equal Footing hero rescue are documented in [the library guide](universal-library.md#start-a-campaign-and-choose-its-path); flagship repairs and diplomacy remain proposals.

## Bring forward: Thrawn’s custom campaign opening

The best next selector is **Learner / Static era / Progressive era** for Thrawn’s *Custom* maps, not a new global difficulty. On the reviewed installation (`1125571106`), `Scripts/Story/GC_MasterScript_GCMenu.lua` (`Infinity_Progression_Choice`, `Load_GC`) sends no tech override for Static, 4 for Progressive and 5 for Learner. Its non-Custom FTGU prompt only offers Static/Progressive. `GCPlayerAgnostic_TR_Custom.lua` reads those sentinels; `GCCustom.lua` gives the learner a standard roster, default heroes and a small start rather than requiring the full sequence of picks. Regular Custom starts can still select their location, roster and heroes in-game.

First acceptance case: **Custom Small, 4 ABY, New Republic**. `GCMenu_FactionsbyMapEra.lua` enables `Custom_Small/4ABY/REBEL`, `XML/Conquests/Custom/Custom_Small_Era_1.xml` declares `Custom_Small_Era_1_Rebel`, and [the current loader test](../tools/test-galactic-story.mjs) already asserts the native progressive handoff. Compare all three arrivals to the original selector, including difficulty, effective progression and the next prompt or learner shortcut. Do not extend a fourth difficulty to normal campaigns, unlock hidden factions or treat later 6 ABY regime branches as equivalent.

## Share: transport losses on auto-resolve

This is a small setting with a visible consequence. I compared the winning `Data/XML/GameConstants.xml` through [the game-file resolver](../tools/megfs.mjs) for stock and each of the six installed overhauls. `AutoResolveTransportLosses` is `0.333333` in stock, both Awakening mods, Thrawn, Fall and Revan; `0.75` in Remake (`1770851727`). It is not the chance of losing an individual ship. After the winner is known, [the casualty routine](../public/js/game/galacticautoresolve.js) computes a *rounded survivor count* for the losing playable side with more than one transport.

Isolated engine check: one 100-power escort against a 10-power escort and four transports, both factions playable, identical rosters, fixed RNG, no special ships or overrun. The same side won both times. Three of the four losing transports survived with the stock term, one with Remake’s. The stock [auto-resolve regression suite](../tools/test-galactic-autoresolve.mjs) also passed with the installation path supplied in memory (the standalone script otherwise expects a sibling game directory). This is a fixture, not an estimate of average casualties.

Offer **Campaign default / alternate sourced loss rule** only where auto-resolve is allowed; keep manual battles, contrast tables and winner/loser power budgets untouched. Check [galactic](../public/js/game/galacticbattles.js) and [tactical auto-resolution](../public/js/game/tacticalautoresolve.js), winning and losing transports, lone transports and hero priority. Persist the resolved rule, not a donor dependency.

## Build as new opt-in mechanics, not copied scripts

- **Hero rescue (first choice for a new objective).** Awakening of the Rebellion (`1397421866`) registers `Story_Rescue_Rebel` in `XML/Conquests/Canon/Plots/STORY_PLOTS_CANON_FULL_REBEL_PLAYER.XML`. `Scripts/STORY/Story_Rescue_Rebel.lua` tracks specific heroes, e.g. Leia, and distinguishes scripted removal from possible death. `Scripts/LIBRARY/libHeroRescueFunctions.lua` looks for a connected, unlocked prison world, preferentially the captor’s. `XML/Story_Rescue_Rebel.xml` ties conquest there to the hero reward. A Universal version should select only host-approved heroes and reachable planets, never override story deaths, and never return a hero twice. Prove save/load while captive and exactly one return. Don’t layer this over a pack’s own rescue/respawn system or enable it without an eligible target.
- **Persistent flagship damage.** Thrawn’s `Scripts/Library/eawx-mod-icw/InstalledPlugins.lua`, `eawx-plugins/persistent-damage-galactic/{init,PersistentDamageGalactic}.lua`, `eawx-plugins-gameobject-space/persistent-damage-tactical/PersistentDamageTactical.lua` and `hardpoint-lists/PersistentDamageLibrary.lua` connect tactical damage to weekly repairs for a named list (including the Executor and Lusankya). A portable version would be original and limited to supported ships. Before offering it, damage one of two identical vessels, retreat, save, resume, and re-enter battle; only the damaged ship should start damaged, with one repair charge per repair. The native plugin uses type/owner keys and the initializer has an explicit permission notice; do not import it as a generic per-vessel system.
- **Diplomatic missions.** Awakening of the Clone Wars (`3387971722`), `XML/Conquests/Big/Plots/STORY_PLOTS_BIG_FULL_REPUBLIC_PLAYER.XML`, registers `Scripts/STORY/AOTCW_Republic_Story_Diplomacy.lua`. The mission uses Padmé at eligible worlds and political capital for time- or use-limited rewards, including intelligence and reinforcements. For Universal, start smaller: an optional envoy mission to earn temporary intelligence. Only offer it with a compatible local agent and world; preserve fog and revoke the benefit on expiry. Do not promise to transfer the Republic’s diplomacy tree or its characters.

I would ship the first two independently; both have a concrete native behavior to compare. The other three would add gameplay and need separate design and save/restore tests.
