# Universal remaster experiments

`universal` is the test branch for improvements that belong in the browser engine, not in a required mod pack. Start with an unmodified copy of Empire at War or Forces of Corruption. Workshop collections are optional workloads; their art direction, models, textures, audio, scripts and balance stay with their authors. Existing mods use the same files and load order as before. There is no new manifest for authors to maintain. For the opt-in single-launch library that builds six local stripped-back profiles, see [Universal campaign library](universal-library.md).

## First change: generate missing texture detail levels with less RAM

At a distance, the renderer samples smaller versions of textures (mipmaps). It already uses artist-supplied chains when present. For supported, single-level DXT1/3/5 textures it builds the smaller versions itself. Previously it decoded the entire top level into temporary RGBA pixels, even though the GPU uses the compressed top level. Now it decodes **16 rows at a time** into a reusable buffer to build the first smaller level. The averaging rule, alpha handling, encoder, and all later levels stay the same. This runs in both the normal texture worker and the main-thread fallback. No changes to quality settings, mod selection, authored mipmaps or battle simulation.

For a synthetic 2048 × 2048 DXT5 texture, the full-size decode temporary was 16 MiB on `main` (`12b0feb`); the strip is 128 KiB. The first output level still needs 4 MiB. Those two RGBA buffers together went from **20 MiB to 4.125 MiB**, verified by tracing the typed-array allocations. All 11 encoded output levels were byte-identical. These are specific CPU-side buffers during mip generation, **not whole-game memory, GPU memory, loading-time or FPS measurements**.

### Reproduce or play

- `npm run test:universal`: 39 entirely synthetic cases across all three DXT formats. Covers narrow textures, non-square dimensions, partial blocks, alpha, strip boundaries and every generated mip. No third-party data needed.
- `npm run test:universal -- --installed`: also sample local game data and saved Workshop primaries, read-only; uses the same Steam discovery as the launcher. Prints aggregates and pass results without exporting any textures. Counts may change with updates.
- `npm start -- --port 8577`: open <http://127.0.0.1:8577/> and choose your own game data. Use this separate origin to compare with `main` without sharing browser saves/settings. The normal Workshop launcher also works with this branch; don't run two launchers on its default ports simultaneously.

## What belongs here next?

A candidate needs a stock-game use case, a repeatable before/after check against `main` and a result that carries over to more than one independent mod family. Preserve authored settings or make visual tradeoffs opt-in. Keep changes isolated until they pass the [fork compatibility checks](fork-mod-compatibility.md). No mods or private libraries in the distribution.

**Measured: [distant fleets vs. weapons and particles](fleet-render.md)** in stock Forces of Corruption and all six primary mods. Mobile hulls were the larger draw cost on this path. Authored lower-detail meshes reduce geometry on some fleets but do not consistently reduce frame time. The WebGL fighter experiment remains opt-in. The [shadow vs. ship submission follow-up](fleet-render-passes.md) measures the shadow map on the GPU and the browser time spent preparing and submitting visible ships, without changing graphics defaults. The [live stock vs. Revan trace](fleet-render-live.md) checks which of those submission costs persist while the battle moves.
