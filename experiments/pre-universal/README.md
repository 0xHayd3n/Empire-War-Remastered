# Pre-Universal prototypes

These are earlier experiments, not imports of the live engine or part of its test suite. The current versions of the player UI, remaster bindings, vegetation and scanned materials live in `public/` at the repository root. The relative paths below `classic/` and `endor/` record where the prototype files were used in their original checkouts; some need earlier APIs. Do not copy them over the current renderer as a group.

- `classic/`: setup-preview module and regression checks for the earlier single-player UI, first visible galaxy frame and preview bounds.
- `endor/`: early surface-detail generator, procedural conifer geometry, foliage checks, and the earlier forest-ground PNG cook and its CC0 source notes. No mounted captures or retail textures are included.
